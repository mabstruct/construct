<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → run_id | run_id (CLI/MCP arg) becomes the SQLite thread_id and influences the checkpoint DB path — untrusted string crossing into persistence/path layer. |
| graph node → workspace filesystem | nodes read the file-based workspace SOT; malformed/oversized inputs could crash a node. |
| node → MCP stdio transport | node stdout is the JSON-RPC channel when invoked via MCP. |
| curation.run → canonical SOT (D-06) | the run must never write canonical facts (cards/refs/connections.json/search-seeds.json/digests/events-as-facts). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering | run_id → thread_id / checkpoint path | mitigate | `_validate_run_id` enforces KEBAB_CASE_PATTERN at the input-model boundary (field_validator on CurationRunInput/CurationInspectInput), identical to research_run (CR-01 / ASVS V5). Input models `extra="forbid"`. |
| T-11-02 | Denial of Service | per-node robustness vs malformed/oversized workspace | mitigate | Each real node wraps its body in try/except → emits a `status="failed"` CurationStepResult with a sanitized reason, so a bad card surfaces as `degraded` (honest) rather than an opaque crash or false `completed`. Scans are O(cards) read-only; bridge_detect already caps L3. |
| T-11-03 | Tampering (transport) | stdout contamination of MCP JSON-RPC | mitigate | Nodes log to stderr via `logging` only; no `print()` (Pitfall 6 / WR-04). Acceptance grep asserts no `print(`. |
| T-11-04 | Tampering | unintended canonical SOT write (D-06 invariant) | mitigate | No node writes canonical facts; decay reports auto_archive but never archives (D-06). bridge_detect's derived log/+views/ writes are classified derived, not canonical (Pitfall 1) — verified by Plan 01 `test_no_canonical_writes`. |
| T-11-06 | Information Disclosure | provider error text if L3 ever runs | accept | bridge_detect already wraps L3 in try/except with class-name-only logging and auto-skips offline; no new secret introduced (ANTHROPIC_API_KEY only optionally read downstream). |
| T-11-SC | Tampering | npm/pip installs | accept | No installs this phase (all deps shipped+vetted Phases 8–10). No supply-chain surface. |
</threat_model>

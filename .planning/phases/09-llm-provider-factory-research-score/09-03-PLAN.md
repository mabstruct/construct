`config={"max_concurrency": N}` via executor.map, but async `ainvoke`/`asyncio.gather`
does NOT bound concurrency. USE THE SYNC PATH — a `ThreadPoolExecutor(max_workers=cap)`
(RESEARCH Pattern 3) or a sync LangGraph `Send` graph. Do NOT use `asyncio.gather`.
`Send` (if used) is `from langgraph.types import Send` (NOT langgraph.constants — deprecated).

Degraded vs outage discrimination (RESEARCH Pitfall 3):
- Per-item failure (invalid/unparseable output): retry once, else skip+reason, count it,
  set gate `degraded=True`, gate still SUCCEEDS with partial good findings (D-08).
- Total outage (ALL items fail on a provider/auth/config cause): promote to a gate-level
  degraded ERROR — the shim (Plan 04) maps this to `success=False`. NOT an all-skip success (D-09).

| batch result -> caller | A run with zero usable findings must not silently report success (masking an outage). |
| gate -> workspace | The runner reads config/taxonomy but MUST NOT write to the workspace SOT. |

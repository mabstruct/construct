    `## Context` — the drift: `nfrs.md` §2 and `architecture-overview.md` §8.2 asserted no database owns
    part of the truth and no derived state is required, while Phase 10 shipped LangGraph `SqliteSaver`
    checkpointers writing `.construct/workflow/research-run.sqlite` and `.construct/workflow/curation-run.sqlite`.
    State the verified control-flow fact concretely: `gate_review` contains only `interrupt(...)`;
    `update_seeds_and_log` is a separate node defined after it; **every** `append_event` call in
    `research_run.py` lives inside `update_seeds_and_log` and therefore runs only after the gate resumes.
    While a run sits at `awaiting_review`, zero events have been appended to `log/events.jsonl`, so the
    scored findings and per-finding default decisions exist **only** in the sqlite checkpoint. Cite the
    file:line evidence.

    `## Decision` — `.construct/workflow/*.sqlite` is intentional durable state. It holds pending
    human-review decisions that are **not reconstructible from layer 1**. It sits **outside** the
    layer 1/2/3 model rather than violating it (note that architecture-overview §4's four invariants are
    each scoped "to layer 2", so workflow checkpoints do not contradict them). The rebuild guarantee is
    scoped to **knowledge state** — `cards/`, `refs/`, `connections.json`, `search-seeds.json`,
    `log/events.jsonl`, `digests/`. Losing a checkpoint costs a completed search+scoring cycle and any
    entered decisions; it never corrupts or loses canonical knowledge. State the blast radius in exactly
    those terms — do not claim the file is backed up, replicated, or recoverable. One decision covers
    both `research-run.sqlite` and `curation-run.sqlite`: they are the identical
    `SqliteSaver(sqlite3.connect(..., check_same_thread=False))` pattern over `.construct/workflow/{name}-run.sqlite`.
    Note the directory is created lazily at first checkpointer construction, is **not** in `REQUIRED_PATHS`,
    and may legitimately be absent.

    `## Options Considered` — three `###` options, each a one-paragraph description followed by
    `**Pros:**` / `**Cons:**` lists, following adr-0002's shape. Mark the chosen one `(this decision)`.
    Option A: record the checkpointer as sanctioned durable state and scope the rebuild guarantee to
    knowledge state (this decision). Option B: make the checkpoint reconstructible by emitting scored
    findings to `log/events.jsonl` before the gate pauses — rejected: it changes runtime behavior, which
    v0.4.1 lists Out of Scope, and it would write unreviewed findings into the audit log. Option C: drop
    the durable checkpointer and hold gate state in memory — rejected: it removes the resumable
    human-review capability Phase 10 shipped and regresses v0.4.

    `## Consequences` — `### Positive` / `### Negative` / `### Neutral`, full-sentence bullets, using
    adr-0002's em-dash "…— addressed by …" mitigation form. Positive: v0.5 can design a resumable
    gate-state UI against a recorded invariant. Negative: workspace portability is now scoped — copying
    only the knowledge files loses in-flight reviews; blast radius is bounded and named. Neutral: adds a
    fourth artifact class to the workspace contract.

    `## Durable orchestration state (artifact class)` — a post-Consequences section (adr-0002 sets this
    precedent with its `## Planning Directory Layout (consequence of this decision)` section). This
    section is **required** by D-12/Q3 and is consumed verbatim in spirit by plan 14-03. Define the class
    name `durable orchestration state`, state what qualifies (holds pending decisions not reconstructible
    from layer 1; not canonical knowledge; not derived from canonical knowledge), name its one current
    member `.construct/workflow/*.sqlite`, and state that it is created lazily and may legitimately be
    absent. Explain why it fits neither existing class: the Support class preamble says support artifacts
    "do not define workspace truth" and the Derived class asserts derived artifacts are never canonical
    inputs — both are false of a checkpoint holding the only copy of pending decisions.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| skill spec -> workspace | The skill's `allowed-tools` grant is the boundary between "delegate to the Python capability" and "write to the workspace directly". A Write/Edit grant would let skill text bypass the Python write-ownership contract. |
| skill spec -> local invoke surface | `Bash(construct)` / `MCP(connect)` let the skill call the local `construct` CLI / `construct mcp` stdio server. daily_run.py already kebab-validates run_id (path traversal) and sanitizes child errors — the skill only invokes; it must add no tool that could write outside that boundary. |

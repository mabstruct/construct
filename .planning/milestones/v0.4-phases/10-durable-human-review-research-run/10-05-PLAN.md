<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI/MCP keyword args → registry handler | External invocation crosses into the workflow; positional vs keyword dispatch must be disciplined (RT-03). |
| handler error → CLI/MCP output | Outage/exception text could leak provider keys into stdout/MCP stream. |
| MCP stdout stream | JSON-RPC transport — any stray stdout corrupts it. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-15 | Info Disclosure | shim error text leaks API key | mitigate | Shims catch ResearchScoreOutageError → safe_message and generic Exception → `_safe_scoring_cause`; never echo raw `str(exc)` (Phase 9 T-09-06). |
| T-10-16 | Tampering (protocol) | stray stdout in handlers corrupts MCP | mitigate | Handlers/runners log to stderr only; no `print(`; result serialized via `_serialize_result` model_dump (WR-04). |
| T-10-17 | Spoofing / Input Validation | malformed CLI/MCP args | mitigate | Input models use `extra="forbid"`; shims raise TypeError on positional misuse; Typer validates option types. |
</threat_model>
